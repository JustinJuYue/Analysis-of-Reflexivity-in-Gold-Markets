# Analysis of Reflexivity in Gold Markets

## Overview
This repository contains the code, data, and visualizations for a statistical investigation into the microstructural dynamics of financial assets. Specifically, it tests George Soros's Theory of Reflexivity against the post-2024 vertical price breakout in Gold. 

By comparing Gold against a purely physical commodity (Sugar) and a purely reflexive digital asset (Bitcoin) across two macroeconomic epochs (1960–2010 and 2010–2026), this project utilizes Autoregressive AR(1) baselines and Generalized Linear Models (GLM) to determine if Gold has lost its historical safe-haven properties and transitioned into a speculative bubble.

## Repository Structure

* `data/` : Contains all raw and processed CSV files.
  * `bitcoin.csv`, `commodity_prices.csv`, `gold.csv`, `sugar.csv`: Raw nominal asset data.
  * `us_cpi.csv`: Consumer Price Index data used for deflating nominal prices.
  * `master_macro_dataset.csv`: The final, cleaned, and merged dataset containing real prices at End-of-Month (ME) frequency.
* `plots/` : High-resolution scientific visualizations generated by the analysis.
  * `Nominal_Real_Price.png`: Macroeconomic epoch plotting (1960-2026).
  * `case_study.png`: Dual-axis plots mapping real prices against dynamic GLM crash probabilities.
* `data_clean.py` : The data engineering pipeline. Programmatically stitches historical data, downsamples to monthly frequency, and calculates CPI-adjusted real prices.
* `Lab.ipynb` : The core analytical Jupyter Notebook containing the statistical modeling, Likelihood Ratio Tests (Wilks' Theorem), and visualization scripts.

## Methodology

### 1. Data Engineering
All nominal asset prices are deflated using the US CPI to reflect true purchasing power in 2026 USD. This removes the macroeconomic bias of currency debasement over the 60-year baseline. Data is resampled to an End-of-Month (ME) frequency to eliminate intraday volatility noise.

### 2. Statistical Modeling
The project employs a dual-model approach:
* **Autoregressive Baseline (AR):** Tests for short-term temporal momentum vs. random walk efficiency.
* **Generalized Linear Model (GLM):** A Logistic (Logit) regression is used to predict the dynamic probability ($\mu_t$) of a severe tail-risk crash (returns dropping below the historical 5th percentile). The independent variable ($X_t$) is the trailing 12-month cumulative log-return, representing the macroeconomic "stretch" or bubble size.

## Key Findings
1. **Bitcoin (Reflexive Baseline):** Validates the Soros framework. Extreme price stretches directly correlate with massive spikes in crash probability ($p < 0.05$).
2. **Sugar (Physical Baseline):** Exhibits a reverse correlation. Massive price stretches indicate genuine physical supply shocks, structurally lowering the probability of a sudden speculative crash.
3. **Gold (The Broken Anchor):** From 1960–2010, Gold behaved structurally like a physical asset experiencing a supply shock during crises. However, post-2024, the model completely breaks down ($p = 0.1430$). The current exponential breakout is forcing traditional safe-haven models to output anomalous near-zero crash probabilities, indicating that the market is systematically mispricing Gold's emerging tail-risk.
